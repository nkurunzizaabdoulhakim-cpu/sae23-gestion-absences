# SAE23 - Gestion des absences

## Description du projet

Ce projet a été réalisé dans le cadre de la SAE23 (Web Dynamique) du BUT Réseaux & Télécommunications.

L’objectif est de développer une application web permettant la gestion des absences des étudiants.

L’application permet :

- Authentification des utilisateurs (enseignant / étudiant)
- Sélection d’un groupe et d’un module
- Affichage des étudiants
- Saisie des absences par créneaux horaires
- Consultation des absences
- Interface interactive avec JavaScript
- Jeux intégrés (Puzzle, Yoda, TP JS)

---

## Technologies utilisées

- PHP (logique serveur)
- MySQL (base de données)
- JavaScript (interactions dynamiques)
- HTML / CSS (interface utilisateur)
- XAMPP (serveur local Apache + MySQL)
