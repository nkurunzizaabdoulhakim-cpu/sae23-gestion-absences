# SAE23 - Gestion des absences

## Installation

1. Cloner le projet dans :
C:\xampp\htdocs\sae23

2. Démarrer Apache + MySQL (XAMPP)

3. Créer la base :
sae23

4. Importer :
database/sae23.sql

5. Copier :
config/config.example.php → config/config.php

6. Ouvrir :
http://localhost/sae23
